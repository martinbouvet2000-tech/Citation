# Placeholders signature AURÉLIA

Visuels temporaires en attendant les vraies photos packshot des produits.
Style éditorial cohérent : ivoire + halo LED couleur du produit.

## Fichiers

| Fichier | Usage | Format |
|---|---|---|
| `hero-aurelia.png` | Section Hero (homepage, Theme Editor) | 1000×1250 |
| `aurelia-signature.png` | Fiche produit Signature | 1000×1250 |
| `aurelia-lumiere-pro.png` | Fiche produit Lumière Pro | 1000×1250 |
| `aurelia-regard.png` | Fiche produit Regard | 1000×1250 |
| `aurelia-decollete.png` | Fiche produit Décolleté | 1000×1250 |
| `le-rituel-complet.png` | Fiche produit Bundle | 1000×1250 |

Les `.svg` sont les sources éditables (couleur, texte) si tu veux ajuster.

## Comment uploader

### Hero (homepage)
Theme Editor → section **Hero** → champ **« Image hero »** → uploader `hero-aurelia.png`

### Fiches produit
Admin → **Produits** → clic sur le produit → section **Médias** → glisser-déposer le PNG correspondant

## Remplacement futur

Quand tu auras les vraies photos packshot (depuis ton fournisseur, ou
prises au smartphone studio), remplace simplement chaque PNG par sa
version finale via le même bouton "Médias" sur la fiche produit.

Les SVG sont éditables dans tout éditeur vectoriel (Figma, Illustrator,
Inkscape) si tu veux ajuster les textes, couleurs ou ajouter ton logo.
